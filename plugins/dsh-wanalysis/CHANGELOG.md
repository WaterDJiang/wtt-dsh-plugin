# 版本记录

## 0.5.2

股票分析与创作工作台在同一 WTT 市场索引内分别安装。Git 安装时选择仓库内的股票分析子目录。

## 0.5.1

- 桌面指标面板按列表长度调整高度。公开指标较少时，「新建指标」「导入」「导出」紧跟列表，长列表可以滚动。
- 增加平安银行日线、周线、数据库同步、指标选择和归档财报的 DSH 实拍。安装、更新和数据故障处理现在有独立图解与说明。

## 0.5.0

- 首次打开时建立本机 SQLite，也可连接已有 Wanalysis v3 库。
- 支持同步选中的股票或沪深京 A 股全市场，显示库内最新交易日及归档证券数。
- 公开版预置筹码集中度，支持本机公式试算、保存与导入导出。
