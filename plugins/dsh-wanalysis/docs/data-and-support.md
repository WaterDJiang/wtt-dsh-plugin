# 数据库、模型与常见问题

## 查数据库时间

| 页面位置 | 时间含义 |
| --- | --- |
| 库内最新交易日 | 整个库里所有前复权归档的最大交易日。旁边的数量是已归档证券数。 |
| 股票名下的日期 | 当前股票最新一根可见 K 线的交易日；停牌或只更新其他股票时可能较早。 |
| 底部「获取于」 | 这份行情的获取时间。 |
| 本机资料 → 最新财报 | 该股已归档的报告期和可用的公告日。 |

只关心一只股票时，选中它，点 **更新数据库 → 同步这只股票**。若想刷新整个市场，选 **同步全部 A 股**，从沪深京 A 股目录最多同时更新 3 只。首次建库用时取决于目录大小、网速和数据源限流。启动后面板自动收起。全市场先按自选顺序更新 A 股收藏，再更新其余证券。单股与全市场都在后台运行，切股、切周期或离开股票页面后仍可继续。点 **查看同步进度** 可看当前证券、已处理数、已跳过数和失败数。

北京时间 15:05 后获取的当日日线，成交量、成交额和换手率齐全时，重复批量更新可复用该股行情；如还缺当天获取的有效财务摘要，会单独请求财务。两者齐全则跳过。盘中、停牌或周末如库内日期与当前日期不同，仍会尝试更新。

每只股票归档完成后都会保存进度。暂停、限流或退出 DSH 后，重新打开同一行情库，点 **继续上次同步 → 继续全市场同步**，即可从剩余证券接着更新。跨日仍先完成原来这一轮。意外退出时，最后正在处理的证券可能重试。部分完成可点 **重试失败股票**；全部完成后再次同步才开始新一轮。断点从 0.5.5 开始记录。

## 文件与联网范围

- **本机存储**　默认库是当前 DSH 数据目录下的 `wtt-wanalysis/行情.sqlite`。点页面顶部的路径可换库。插件在原文件中写入更新，重启后会恢复选中的库。自选、布局与个人公式另存于当前配置的偏好库。
- **离线使用**　可查已归档的股票、切换日周线、读财务及计算已有公式。新库需要联网同步或连接已有行情库。
- **行情来源**　联网同步会向 Wanalysis 服务请求所选证券代码、复权口径和历史窗口。沪深前复权备用历史优先从东方财富一次取得日线、成交额和换手率。后备路径从腾讯取日线、从搜狐补充成交额与换手率。全市场目录来自巨潮资讯。单次历史窗口依来源最多 2,000 根日线，备用窗口最多 640 根。
- **模型生成**　在指标面板点 **新建指标** 或 **编辑**，输入说明后点 **生成公式**。插件调用 DSH 当前默认文本模型。要用本地模型，先在 DSH 中配置它并选作默认文本模型。只有勾选附带当前公式时，已有公式才随说明发送。检查草稿后点 **保存并应用**，用本机行情试算并保存。

## 遇到问题

| 现象 | 操作 |
| --- | --- |
| 搜到股票，但图表为空 | 核对代码和复权选项，点 **更新数据库 → 同步这只股票**。联网时可搜索尚未归档的证券。 |
| 顶部提示文件不存在或没有权限 | 点顶部路径，选回可读写的原 SQLite。若确实要开始一个新库，明确选择 **新建数据库…**。 |
| 最新交易日落后或出现「可检查更新」 | 先看当前股票自己的日期，再按需同步。周末、节假日或停牌时可能没有新 K 线。 |
| 数据库更新失败 | 查看面板里的具体错误，检查连接与文件写权限。可先查看已有归档；全量任务恢复后可继续或重试失败项。 |
| 财务字段为空、勾了指标却看不到副图 | 展开 **本机资料** 核对归档，选中前复权并同步当前股票。在 **指标** 面板查看试算提示；缺成交额或换手率时，依赖该字段的公式可能没有有效输出。 |
| 想看盘中报价 | 联网点底部 **最新报价**，按返回的报价时间判断时效。 |
