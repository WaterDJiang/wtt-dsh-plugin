# 使用案例：从一份需求做到可编辑课件

下面以虚构的《Excel 数据整理与分析入门》为例。可以用仓库的[样例资料](../plugins/dsh-creation-workbench/样例数据)练习，也可以换成自己的文档。界面以实际安装的插件版本为准。

**需求 → 课程大纲 → PPT 设计 → 可编辑 PPT → 修改与定稿**

| 阶段 | 在工作台怎么做 | 这一步留下什么 |
| --- | --- | --- |
| 需求 | 打开本机项目，把需求文档拖进画布。补充学员、课时、目标和约束。 | 需求或资料卡 |
| 课程大纲 | 从需求卡点「＋ → 文本」，按需要选择大纲类本机 Skill。审阅章节、时间和练习。 | 可再次引用的确认版大纲 |
| PPT 设计 | 从大纲卡接出分镜，逐页明确内容、画面、演示和练习时机。 | 已审阅的分镜与制作资料 |
| 可编辑 PPT | 引用确认版分镜和模板，创建 PPT 任务。可先做少量页面，再扩展到整套。 | PPTX，以及任务记录中的制作资料和检查报告 |
| 修改与定稿 | 双击卡片看逐页预览。用「编辑源文件」进入匹配的源工程，或用「打开 PPT」交给本机应用。 | 可回看的同卡新版本 |

## 关键交互

- **从现有内容往下接。** 在确认版大纲旁点「＋」，新卡自带这份大纲。用 `@` 或「＋ 添加」补充素材，发送前核对引用。以后看成果卡上的连线，可以找到这一步接的是哪份资料。
- **把确认留在对应的任务。** 要选择方案或审阅样章时，从任务提示打开原对话，先看实际文件再回复。生成的课件和验收资料也可以分别查找。
- **对着页面修改。** PPT 右栏可以逐页看。有匹配的 SVG 或已关联的网页工程时，使用对应编辑器。SVG 源稿可以原位改字、编辑讲师备注，并把页面或对象交给 AI。查看候选后确认应用，再保存新版。
- **文件有落点。** 正式成果在所选项目目录中，卡片可定位文件或切换历史版本。用本机应用编辑时，先在工作副本上修改，再按需要归档新版。

## 可以从任意一步开始

手里已有大纲就从分镜开始。已有课件就直接拖入预览，或者以它为资料继续做讲稿、练习和手册。要练习第一个操作，可以把一份 Markdown 文件拖进画布，从卡边「＋ → 文本」发起摘要任务。

同样的交互也适合营销、脚本和调研。工作台负责项目文件、引用、任务和版本，各行业的创作步骤由你选用的模型或本机 Skill 决定。课程技能、知识库和企业模板需要自行准备。
